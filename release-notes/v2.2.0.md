## xrick 2.2.0

**xrick is now also on [itch.io](https://senjinthedragon.itch.io/rick-dangerous)**, playable directly in the browser there, alongside the existing GitHub Releases and GitHub Pages.

### Added

- A native Windows ARM64 build, alongside the existing x64 one - no emulation needed on an ARM64 Windows PC (Surface Pro X/11 and similar). Cross-compiled in CI from an ordinary x64 runner; untested on real ARM64 Windows hardware, so treat it as best-effort for now, same as the macOS build.
- macOS gets the real CRT shaders, FSR upscaling, and bezels now - the same look Linux and Windows have had all along. They're transpiled from the same shader source to Metal's own shading language at build time.
- On macOS, every F-key shortcut (fullscreen, zoom, mute, volume, upscaler/CRT/bezel cycling) also works as Option+1 through Option+9, in the same order as the F-keys themselves. Apple keyboards route bare F-keys to media controls by default, and F11 specifically is reserved by the OS for "Show Desktop" no matter what - so this is the only reliable way to reach those shortcuts on a Mac without changing system settings.

### Changed

- The macOS build now gets a quick CI smoke test on its actual arm64 slice (macos-latest runners are Apple Silicon) - catches a binary that fails to even start (missing library, bad path) before it ships, though it still can't test rendering, audio, or anything that needs a real display.
- README updated to cover the Windows ARM64 build, the macOS universal binary, and the itch.io page.

### Downloads

- Linux and Windows x64 binaries are built and tested by us.
- The Windows ARM64 and macOS binaries are built by CI but not tested on real hardware - treat them as best-effort, including the new macOS shaders above.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: on [GitHub Pages](https://senjinthedragon.github.io/xrick/) or on [itch.io](https://senjinthedragon.itch.io/rick-dangerous).
