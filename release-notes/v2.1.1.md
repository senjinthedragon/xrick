## xrick 2.1.1

A small follow-up focused entirely on the web build's player page: a visual refresh, and real fullscreen fixes underneath it.

### Web player page

- A themed reskin of the page the game actually plays on - warm torch-lit colors, a drifting background glow, embers, and a torch-flicker on the title - instead of the plain dark dev-page look it had before.
- Fullscreen now actually redraws at your screen's real resolution instead of just CSS-stretching the small windowed canvas - the CRT shaders and bezel are sharp in fullscreen again, matching what the in-game settings menu's own FULLSCREEN toggle has always done.
- Fixed: going fullscreen *before* starting the game, then starting, used to drop back out of fullscreen (SDL resizing its own window as part of starting up, independently of the browser-level fullscreen the page had just requested). Starting the game first, then going fullscreen, is unaffected either way.
- Fixed: rotating a phone while already fullscreen left the game sized for the old orientation - far too small to tap. It now re-syncs on every rotation, not just on first entering fullscreen.
- Fixed (Firefox specifically): the fullscreen-exit and settings-menu overlay buttons, and the fullscreen canvas resize itself, were silently not applying at all - caused by combining the standard and old WebKit-prefixed fullscreen CSS selectors in a single comma list, which Firefox discards entirely over the one prefix it doesn't recognize.
- The fullscreen-exit and settings-menu overlay buttons are now shown only on touch devices - a desktop player already has Escape and Tab for the same thing, with a visible mouse cursor that's hidden during normal play anyway.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI only - neither of us can run or test it, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
