## xrick 2.1.0

A mostly mobile-focused follow-up to 2.0.0, plus a couple of fixes that affect every platform.

### Mobile web

- The web build is now actually playable on a phone:
  - A real fix for the canvas sometimes staying blank after tapping start (the browser-side cause, and the fix, are both in the commit history for anyone curious).
  - Fullscreen now has a way to leave it again - an on-screen button, bottom-right, visible only while fullscreen.
  - A matching settings-menu button, bottom-left, for the same reason: the normal menu button isn't reachable once fullscreen either.
  - The diskette carousel now supports touch: tap near an arrow (or swipe) to switch games, tap the middle to launch.
  - Every settings-menu row is now tappable, not just scrollable with a d-pad.
  - A 9-zone on-screen touch control scheme for actual gameplay (jump, move, shoot, fire, bomb), supporting multiple simultaneous touches.
  - QUIT GAME removed from the web build's menu - there's no process to exit to, so it only ever tore the canvas down for nothing.

### Fixed for everyone

- RD2 could hang completely, with a solid red screen, right at the very end of the game (finishing World 4). This was a genuine, 35-year-old bug in the original 1990 release - "map 5" was never a real level, so the original loader span forever trying to load it - faithfully carried over by the decompilation. Patched so finishing the game actually ends it now, for autoplay and real players alike.
- The settings menu's hotkey moved from Escape to TAB, on every platform, not just the web build - Escape doubles as a browser's own fullscreen-exit key, which made the menu unreachable while fullscreen in a desktop browser too. Autoplay/demo now stops on any key, not just the menu hotkey.

### New

- STORE HIGHSCORES, under the GAME settings page, off by default. Neither game has ever actually saved its high-score table before now; turning this on makes a win survive a restart instead of resetting every time.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI only - neither of us can run or test it, so treat it as best-effort.
- The web build is now also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
