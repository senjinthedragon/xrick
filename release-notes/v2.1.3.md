## xrick 2.1.3

A small but important Windows fix, found by actually testing the Windows build on real Windows for the first time (previously only ever built and smoke-tested via Wine).

### Fixed

- The Windows build (xrick.exe) failed to even start on a clean Windows install: "The code execution cannot proceed because VCRUNTIME140.dll was not found." The build linked the Visual C++ runtime dynamically, which needs the Microsoft Visual C++ Redistributable installed - present on any machine with Visual Studio on it (which is why this went unnoticed), absent on a regular user's PC. The runtime is now statically linked into the .exe, so nothing extra needs installing.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI only - neither of us can run or test it, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
