## xrick 2.1.6

Two more Windows fixes, both found by testing in a real Windows 11 VM: the real fix for the missing-DLL issue chased across 2.1.3-2.1.5, and an unrelated console-window annoyance.

### Fixed

- "VCRUNTIME140.dll was not found" is fixed for real this time, properly: the Windows zip now includes vc_redist.x64.exe, Microsoft's own Visual C++ Redistributable installer, unmodified. Run it once per PC (not once per game) if xrick.exe doesn't start - see the included README.txt. Several earlier attempts (2.1.3-2.1.5) tried bundling loose runtime DLLs instead to avoid needing an installer at all; confirmed in testing that this genuinely doesn't work on every Windows install, so the installer is the one that actually works.
- xrick.exe no longer pops up a console window when launched normally (double-clicking it, or from a shortcut). It still reuses an existing terminal's console for debug output if you run it from one - that was never the problem, Windows itself was auto-creating a brand new console window for every launch with no parent one.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI only - neither of us can run or test it, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
