## xrick 2.1.9

The credits get it right this time: the full original Rick Dangerous team, confirmed directly by Simon Phipps himself.

### Changed

- Removed Ben Daglish from the credits (confirmed by Simon: he wasn't actually on the project - an earlier secondary source had this wrong).
- Added Bob 'Goth' Churchill and Robert Toone's full role.
- The in-game CREDITS screen and the README's Credits section now both list: Simon Phipps, Terry Lloyd, Robert Toone, Bob 'Goth' Churchill, Stuart 'Dangerstu' Gregg, and David 'Ken' Pridmore - with their actual roles.
- General readability pass on the credits screen: consistent spacing after every section heading, and name-first/role-below ordering throughout (a couple of entries had this backwards before).

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI only - neither of us can run or test it, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
