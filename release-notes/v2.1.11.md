## xrick 2.1.11

### Changed

- macOS now gets the real CRT shaders, FSR upscaling, and bezels - the same look Linux and Windows have had all along. They're transpiled from the same SPIR-V to Metal's own shader language at build time, so there's no behavior difference beyond "it actually renders" on a Metal GPU. On the rare GPU that still can't run them, the plain-renderer fallback from v2.1.10 is still there as a safety net.
- On macOS, every F-key shortcut (fullscreen, zoom, mute, volume, upscaler/CRT/bezel cycling) now also works as Option+1 through Option+9, in the same order as the F-keys themselves. Apple keyboards route bare F-keys to media controls by default, and F11 specifically is reserved by the OS for "Show Desktop" no matter what - so this is the only reliable way to reach those shortcuts on a Mac without changing system settings.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI and tested by us in a VM, but without GPU acceleration - audio and native-hardware behavior, including the new shaders above, are still unverified on a real Mac, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
