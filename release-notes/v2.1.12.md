## xrick 2.1.12

### Added

- A native Windows ARM64 build, alongside the existing x64 one - no emulation needed on an ARM64 Windows PC (Surface Pro X/11 and similar). Cross-compiled in CI from an ordinary x64 runner; completely untested on real ARM64 Windows hardware, so treat it as best-effort for now, same as the macOS build.

### Changed

- The macOS build now gets a quick CI smoke test on its actual arm64 slice (macos-latest runners are Apple Silicon) - catches a binary that fails to even start (missing library, bad path) before it ships, though it still can't test rendering, audio, or anything that needs a real display.

### Downloads

- Linux and Windows x64 binaries are built and tested by us.
- The Windows ARM64 and macOS binaries are built by CI but not tested on real hardware - treat them as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
