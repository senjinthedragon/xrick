## xrick 2.1.2

A tiny, purely cosmetic/packaging release - no gameplay or page changes, just making sure the icon already sitting in xrick/icons actually shows up everywhere it reasonably can, plus some missing file metadata on Windows.

### Icons

- The web build now has a proper favicon (the browser tab icon), using the same Atari ST-style portrait as the Windows build's icon.
- The Windows .exe has always had this icon; it's unchanged, just confirmed.
- The Linux build now ships an optional .desktop file + icon (see xrick/linux/README.txt in the zip) - a raw Linux binary can't embed an icon the way Windows/macOS can, so this is the freedesktop.org equivalent, opt-in since it needs you to fill in where you actually extracted the release to.
- The macOS build is now a real xrick.app bundle instead of a bare binary + dylib, so it finally gets an icon too (built from the same source art, scaled up with nearest-neighbor so it stays crisp pixel art rather than going blurry).

### Windows file info

- The .exe now reports proper file details (right-click -> Properties -> Details): company (DragonFox Inc.), description, version, and copyright. Previously these were all blank.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI only - neither of us can run or test it, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
