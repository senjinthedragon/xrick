## xrick 2.0.0

This release merges upstream's Rick Dangerous II, the real Atari-hardware audio engine (Musashi 68k + YM2149, running the actual original sound driver code), and the Emscripten web player with this fork's own SDL_GPU renderer, settings menu, gamepad remapping, and diskette carousel. Both games now ship in one binary, switchable from the carousel.

### Highlights

- Rick Dangerous II, playable end to end, sharing this fork's renderer/menu/gamepad code with Rick Dangerous I.
- Real Atari ST audio engine for both games (Musashi + YM2149), replacing the old WAV/Ogg conversion.
- Diskette carousel to pick a game: title music chained sting-then-loop, a floor reflection, a confirm scream, and a "small CRT speaker" lo-fi coloring on the carousel's own music (gameplay audio is untouched - it stays bit-identical to the real hardware sound).
- QUIT TO MENU, added to the settings menu - leaves a run and returns to the carousel without losing anything.
- A proper Windows build: the MSVC project (xrick.vcxproj) previously built only upstream's bare OpenGL RD1+RD2 tree and had silently never been updated for this fork's own work. It now builds the real SDL_GPU/menu/carousel feature set.
- Web build deployed to GitHub Pages - play either game directly in a browser.

### Fixes found while integrating

- Menu/credits stutter, and menu input speed tied to game speed.
- Rick Dangerous II's autoplay demo never actually started.
- Rick Dangerous I's autoplay demo warped to the wrong map.
- Fullscreen toggle not resetting zoom.
- Rick Dangerous II playing silently when launched from the carousel.
- Death scream sound effect sometimes not playing, or cutting off early - both games' sound engines (like the originals) can't play music and a one-shot sample at once, so the scream now explicitly silences the current track first.
