## xrick 2.1.5

A second follow-up to the Windows launch fix (2.1.3, 2.1.4) - found by testing each attempt in the same real Windows 11 VM.

### Fixed

- xrick.exe still failed with "VCRUNTIME140.dll was not found" even with that exact file sitting right next to the exe (confirmed genuinely present, correct architecture, not a stale old build - exit code 0xC0000135/STATUS_DLL_NOT_FOUND from a direct PowerShell run). The actual cause: vcruntime140.dll itself depends on several api-ms-win-crt-*.dll forwarder stubs, which Windows 10/11 normally resolves internally with no physical files needed - except, apparently, not reliably on this particular VM. The release zip now also bundles the Universal CRT redistributable DLLs (the same files Microsoft's own UCRT Redistributable package installs), removing the dependency on that OS-level mechanism working at all.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI only - neither of us can run or test it, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
