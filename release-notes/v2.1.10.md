## xrick 2.1.10

The first real macOS release, tested in an actual macOS VM.

### Changed

- The macOS build is now a universal binary (Intel + Apple Silicon), targeting macOS 11+. Earlier macOS releases (v2.1.9 and before) were Apple Silicon only.
- On a GPU that can't do the SDL_GPU shader pipeline (every Mac, for now - see below), the game no longer silently loses its settings menu and on-screen display: TAB still opens the menu, the OSD still shows, your zoom/fullscreen choice is remembered correctly, and the CRT/upscaler/bezel hotkeys (F10-F12) now honestly say "NO GPU SHADERS" instead of pretending to switch something that isn't there.
- The README now has a Downloads section with a note on getting past Gatekeeper for the (unsigned) macOS build.

### Known limitation

- macOS doesn't get CRT shaders, FSR upscaling, or bezels yet - the shader pipeline is written in SPIR-V, which Metal can't run directly. It falls back cleanly to the plain renderer (see above) rather than failing to start. A real fix (transpiling to Metal's own shader language) is planned.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI and tested by us in a VM, but without GPU acceleration (see above) - audio and native-hardware behavior are still unverified, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
