## xrick 2.1.7

A small, personal one: the in-game credits scroll and the README now thank the actual people who made Rick Dangerous in the first place - Simon Phipps, Terry Lloyd, Ben Daglish, and David 'Ken' Pridmore. Overdue, and timed for a good reason: Simon got in touch after finding this fork, and he's meeting up with Terry this week.

### Changed

- The CREDITS page (settings menu) and the README's Credits section both now include the original Core Design team by name.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI only - neither of us can run or test it, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
