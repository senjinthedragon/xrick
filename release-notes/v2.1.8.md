## xrick 2.1.8

A quick follow-up to 2.1.7: two more names added to the credits for the original Rick Dangerous team - Robert Toone and Stuart Gregg, alongside Simon Phipps, Terry Lloyd, Ben Daglish, and David 'Ken' Pridmore.

### Changed

- The CREDITS page (settings menu) and the README's Credits section both now include the full original team by name.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI only - neither of us can run or test it, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
