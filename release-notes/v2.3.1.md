## xrick 2.3.1

### Fixed

- F2/F3 (zoom) and window resizing now work on native Wayland desktops where the compositor doesn't honour a plain resize request from the app (confirmed on Hyprland, for floating windows). The window is now created resizable, and the picture itself scales to fit whatever size the window actually is - letterboxed if it's bigger than the current zoom preset, cropped at the edges if it's smaller - rather than quietly doing nothing when the OS-level resize gets ignored. On compositors that do honour the resize request (KDE/KWin), nothing changes: the window still grows and shrinks to match.
- Leaving fullscreen now restores to wherever the window actually was, including a plain drag-resize, instead of always snapping back to the last integer zoom step.

### Downloads

- Linux and Windows x64 binaries are built and tested by us.
- The Windows ARM64 and macOS binaries are built by CI but not tested on real hardware - treat them as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: on [GitHub Pages](https://senjinthedragon.github.io/xrick/) or on [itch.io](https://senjinthedragon.itch.io/rick-dangerous).
