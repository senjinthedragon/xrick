## xrick 2.1.4

A follow-up to 2.1.3's Windows fix, which turned out to be incomplete - found by testing 2.1.3 in the same real Windows 11 VM.

### Fixed

- xrick.exe still failed to start with "VCRUNTIME140.dll was not found," even after 2.1.3 statically linked our own code's C runtime. The actual source of that dependency was SDL3.dll itself (built via vcpkg's dynamic triplet), not xrick.exe - 2.1.3's fix addressed the wrong half. The release zip now also bundles the two small Microsoft redistributable DLLs (vcruntime140.dll, vcruntime140_1.dll) that SDL3.dll needs, the same way SDL3.dll itself was already being bundled. These are Microsoft's own files, meant for exactly this kind of plain-folder deployment.

### Downloads

- Linux and Windows binaries are built and tested by us.
- The macOS binary is built by CI only - neither of us can run or test it, so treat it as best-effort.
- The web build is also downloadable as a zip (serve it over any plain HTTP server; .wasm needs to be served as application/wasm, which most servers already do by default).
- Play in a browser with no download at all: https://senjinthedragon.github.io/xrick/
