xrick for Windows
==================

If xrick.exe doesn't start, or you see an error mentioning a missing DLL
(VCRUNTIME140.dll or similar), run vc_redist.x64.exe once. That's
Microsoft's own Visual C++ Redistributable installer, included here
unmodified -- a lot of Windows games need it, and a clean Windows
install doesn't always have it already.

You only need to run it once per PC, not once per game.
